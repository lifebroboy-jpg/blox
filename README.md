# Blox Craft — Minecraft × Blox Fruits
Мод для **Minecraft Java Edition 1.21.1** на **NeoForge 21.1.x**.

## Что внутри
- **10 дьявольских фруктов** (Песок, Резина, Пламя, Лёд, Свет, Магма, Землетрясение, Будда, Тьма, Дракон), по 3 способности на **Z / X / C**, пассивки, мастерство (открывает X и C), энергия и перезарядки.
- **8 мечей** (Катана … Проклятые двойные катаны): требования к уровню, эффекты удара, ПКМ — волна клинка (30 энергии).
- **Уровни 1–700**: опыт за убийства, +урон и +здоровье от уровня, HUD слева сверху.
- **Квесты и белли**: 7 заказчиков (убей N мобов / охота на босса), торговцы фруктами (стоком по дням) и мечами.
- **7 боссов** с боссбаром и способностями (удар по земле, призыв прислужников, рывок), дроп фруктов и мечей, респаун.
- **7 островов**, строятся автоматически при первом запуске мира: Деревня пиратов, Джунгли, Пустыня, Ледяная деревня, Магмовая деревня, Крепость дозора, Небесный остров. На каждом домик, сундук, квестодатель, торговцы, декор и босс.
- **Лог-пос**: ПКМ — стрелка на ближайший остров, Shift+ПКМ — список координат.

## Игровой процесс
1. Возьмите фрукт (креатив-вкладка *Blox Craft*, сундук на острове, торговец, босс, редкий дроп с мобов).
2. **Присесть + ПКМ** — съесть. Способности: **Z / X / C** (меняются в настройках управления).
3. Берите квесты у NPC, качайте уровень, копите белли, покупайте мечи (Shift+ПКМ по торговцу).
4. Лог-пос покажет путь к островам (дальность 220–2000 блоков от спавна).

## Команды
Для всех: `/bf stats`, `/bf islands`
Для операторов: `/bf level <1-700>`, `/bf beli <n>`, `/bf eat <fruit>`, `/bf boss <type>`,
`/bf island build <id>` (строит остров там, где вы стоите), `/bf island tp <id>`, `/bf reset`

## Установка (игроку)
1. Установите Java 21 и **NeoForge 21.1.x для Minecraft 1.21.1** (neoforged.net).
2. Положите `bloxcraft-1.0.0.jar` в папку `mods`. Для сервера — тот же jar в `mods` сервера.
3. Запустите игру. Острова построятся в течение 1–2 минут после входа в новый мир.

## Сборка из исходников
1. Установите **JDK 21** и Gradle 8.8+ (или возьмите `gradlew` и папку `gradle/` из NeoForge MDK).
2. В корне проекта: `gradle wrapper` (если нет gradlew), затем:
   - `./gradlew build` → jar в `build/libs/`
   - `./gradlew runClient` — запуск клиента для разработки
   - `./gradlew runServer` — запуск сервера
3. Если Gradle не находит плагин/версию, сверьтесь с актуальным NeoForge MDK 1.21.1 и поправьте `neo_version` в `gradle.properties` и версию плагина `net.neoforged.moddev` в `build.gradle`.

## Настройка (`config/bloxcraft-common.toml`)
`autoGenerateIslands`, `bossRespawnTicks`, `fruitDropChance`.

## Заметки
- Острова строятся над уровнем моря (Y=64), небесный — на Y=170. Лучше всего в океане; на суше срежут рельеф. Вручную: `/bf island build <id>`.
- Текстуры сгенерированы скриптом `tools/generate_assets.py` (пиксель-арт-заглушки); замените PNG в `assets/bloxcraft/textures/` на свои.
- Баланс (опыт, цены, HP боссов) — в `data/*.java`.

## Быстрая сборка jar без установки Java
1. Создайте репозиторий на GitHub и загрузите туда содержимое проекта.
2. Вкладка **Actions → Build mod jar → Run workflow**.
3. Через 2–4 минуты скачайте артефакт `bloxcraft-jar` — внутри `bloxcraft-1.0.0.jar`.
Локально: `./gradlew build` (нужна JDK 21), jar появится в `build/libs/`.
